# SafeWalk

SafeWalk is a starter structure for a safer-walking map and live tracking experience.

## Project files

- `index.html` — map and route planning page
- `track.html` — live tracking page
- `css/style.css` — shared styles
- `js/map.js` — map and route behavior
- `js/score.js` — route safety scoring
- `js/share.js` — sharing behavior
- `js/firebase.js` — shared Firebase configuration
- `data/zones.json` — mock safety-zone data

The pages are scaffolds; map, routing, tracking, and Firebase integrations still need configuration and implementation.
